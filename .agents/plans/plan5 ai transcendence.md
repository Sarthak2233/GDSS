## Plan: Phase 5 AI Transcendence

Turn the current collection of Phase 5 helper modules into a complete, explainable, local-first suggestion product. The implementation will first repair the verification baseline, then harden deterministic contracts and anchoring, wire a real suggestion pipeline, add explicit local-model and CLI/API surfaces, and only mark the phase complete after the full harness is green. The intended workspace artifact is `/home/sarakb/projects/GDSS/.cursor/plans/phase5-ai-transcendence_implementation.plan.md`.

**Decisions**
- Keep LangGraph out of Phase 5. `phase5a-agent-orchestration` remains the optional successor and must orchestrate, never replace, Phase 5 deterministic modules.
- Keep all source edits and Git mutations out of Phase 5. `phase6-human-approved-apply` remains the only future file-write path.
- The user selected an opt-in loopback API that may return source-bearing prompts or generated patches. Default API responses remain metadata-only; source-bearing responses require explicit server opt-in, a local token, restricted CORS, and must never enter telemetry, logs, or remote services.
- `gdss suggest --llm` must not silently download a multi-gigabyte model. `gdss model install` / `gdss model ensure` are explicit user commands; a missing model returns WHAT / WHY / FIX.
- Correct the feature queue so it has no circular lifecycle: `phase4f-conflict-topology` is deterministic groundwork, `phase5-ai` is deterministic ranked suggestions and review output, `phase5b-local-model` adds Ollama management, and `phase5c-patch-combinations` adds LLM generation plus validation. Make `phase5a-agent-orchestration` depend on the completed suggestion/model/combo path rather than the incomplete umbrella alone.

**Scope Boundaries**
- Included: deterministic suggestion generation, exact anchors, local-model drafts, validation gate, model management, CLI, local API, privacy controls, tests, docs, queue state, and verification.
- Excluded: LangGraph execution/checkpointing, automatic source edits, Git mutation, autonomous strategy selection, cloud providers, SaaS telemetry changes, frontend F8 implementation, geometric metric/transport research, and full validation sandbox execution from Phase 6.

**Further Considerations**
1. The source-bearing local API choice requires updating the current metadata-only contract and frontend threat model. 3. Start `phase5a-agent-orchestration` only after the enhanced deterministic and model paths are complete. Its LangGraph checkpoints should store IDs, hashes, and metadata, not raw source or patch bodies by default.
